# Changelog

## 0.1.0 — 2026-10-16

First public beta for Minecraft 26.3 (Fabric, client only).

- Trackpad scrolling on the hotbar moves a few slots per swipe, with adjustable speed and optional
  momentum.
- Menus and inventories scroll with momentum again.
- Command + Q drops a whole stack.
- Mods that open a file picker no longer crash the game on macOS.
- Quitting the game is instant even when a mod leaves background tasks running.
- Leaving a world with Distant Horizons no longer freezes the game.
- Reverse scrolling and a scroll lock while attacking, on every system.
- Settings page under Options → Controls → AppleFix… (and Mod Menu).
